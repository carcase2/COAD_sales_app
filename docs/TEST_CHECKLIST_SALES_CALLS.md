- Supabase Edge `notify-new-call` 로그 (INSERT 이벤트만 처리)

- Firebase / `FIREBASE_SERVICE_ACCOUNT` 설정
- Play 설치본 + 알림 권한

## 5. 상담내용 입력 (상세 화면)

접수 건 **상세** → **「N차 상담내용 입력」** 바텀시트. 저장 시 `call_history` 추가 + `next_scheduled_date`·`call_stage`·`status_id` 갱신.

| # | 시나리오 | 기대 결과 | Pass |
|---|----------|-----------|------|
| 5.1 | 상세 진입 | 접수 정보·문의내용·기존 **상담 이력** 표시 | ☐ |
| 5.2 | **상담내용 입력** 버튼 탭 | 바텀시트: 이전 문의/이력 요약, 입력란, 상담 결과, 예정일 | ☐ |
| 5.3 | 상담내용 **비우고** 저장 | "상담내용을 입력해주세요." 오류 | ☐ |
| 5.4 | 상담내용 + **상담 결과**(미결정/수주/미수주/기타/단순문의) + **다음 예정일** 선택 후 저장 | "상담내용 및 이력이 저장되었습니다." | ☐ |
| 5.4a | **다음 예정일** 날짜 선택 | 해당 날짜에 이미 예정된 팔로우 건수 안내, **이 날짜로** / **다른 날 선택** | ☐ |
| 5.5 | 저장 후 상세 | **상담 이력**에 신규 행 추가, 단계(`call_stage`) 증가(예: 1차→2차) | ☐ |
| 5.6 | 저장 후 `next_scheduled_date` | 선택한 날짜로 DB·화면 반영 | ☐ |
| 5.7 | 상담 이력 카드 **스와이프** (있는 경우) | 삭제/동작 정상 | ☐ |
| 5.8 | 상세 **편집 모드** (필드 수정) | 저장 시 Supabase 반영 | ☐ |
| 5.9 | 이미지 추가·삭제 | B2 URL 갱신 | ☐ |

**단순 문의 접수 건:** 접수 시 `call_stage` 종료 → 팔로우·상담 입력 흐름이 일반 건과 다를 수 있음 → 별도 1건 확인.

## 6. 팔로우 (날짜·목록·홈)

팔로우 기준: **`next_scheduled_date`(다음 상담 예정일)**. 미종료(`status_id` ∉ 수주·미수주·단순문의) + 단순문의 제외.

| # | 시나리오 | 기대 결과 | Pass |
|---|----------|-----------|------|
| 6.1 | 5.4에서 **내일(또는 특정일)** 예정일 저장 | 해당 날짜 팔로우 대상이 됨 | ☐ |
| 6.2 | 홈 **오늘 팔로우** 숫자 탭 | 오늘 `next_scheduled_date` 목록 (`오늘 날짜 팔로우`) | ☐ |
| 6.3 | 홈 **금주 팔로우** / **금월 팔로우** | 구간 목록 (`followRange`) | ☐ |
| 6.4 | 상담현황 **달력** 탭 | 예정일별 건수·날짜 선택 시 목록 | ☐ |
| 6.5 | 달력에서 **오늘** 선택 | 오늘 팔로우 건과 6.2 목록 **건수·건 일치** | ☐ |
| 6.6 | 목록 **담당자 필터** (전체/본인 등) | 담당별 건수·목록 맞음 | ☐ |
| 6.7 | **수주·미수주·단순문의**로 종료한 건 | 해당 날짜 팔로우 목록에서 **제외** | ☐ |
| 6.8 | 팔로우 목록 → 건 탭 | 상세 → 5번 상담내용 입력 연속 테스트 | ☐ |

**홈 바텀시트:** 날짜 팔로우 → 담당자 선택 → 목록 (건수 1000건 제한 시 안내 확인).
